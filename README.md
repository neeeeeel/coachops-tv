# CoachOps on a TV

CoachOps's Chromecast page: plays a swim clip on the TV with its times. A phone running CoachOps
starts it on a Chromecast and tells it what to play. The page itself stores nothing and sends nothing.

Published with GitHub Pages at https://neeeeeel.github.io/coachops-tv/. The source of truth is
`coachops/cast_receiver/` in the CoachOps repo; copy changes here from there.
